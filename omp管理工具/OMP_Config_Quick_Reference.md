## ✅ 可以安全操作的内容

### 1️⃣ 切换 AI 模型（日常最常用）
**操作**：在 OMP 里按 `Ctrl+P`  
**效果**：模型按 `小模型 → 主模型 → 大模型` 循环切换  

| 模型 | 什么时候用 | 特点 |
|------|-----------|------|
| **小模型 (smol)** | 简单问答、翻译、总结 | 快、省钱 |
| **主模型 (default)** | 日常对话、写代码、查资料 | 均衡（默认） |
| **大模型 (slow)** | 复杂分析、深度思考、方案设计 | 准、但慢 |

> 💡 **比喻**：就像手机的性能模式，日常用"均衡"，玩游戏开"性能"，省电开"节能"。

---

### 2️⃣ 调整 AI 思考深度
**操作**：在 OMP 里按 `Shift+Tab`  

| 级别 | 适用场景 | 特点 |
|------|---------|------|
| **minimal** | 纯聊天、查简单信息 | 秒回 |
| **low** | 写代码、查资料 | 快 |
| **medium** | 做方案、分析数据 | 准（推荐） |
| **high / xhigh** | 复杂架构设计、深度推理 | 最准，但慢 |

---

### 3️⃣ 登录新的 AI 服务
**场景**：公司新买了 ChatGPT、Cursor、GitHub Copilot 等服务，要接入 OMP  

**操作**：在终端（Git Bash）运行：
```bash
omp auth-broker login 服务名
```

**常用服务名**：
```bash
omp auth-broker login cursor          # Cursor
omp auth-broker login openai          # ChatGPT
omp auth-broker login github-copilot  # GitHub Copilot
omp auth-broker login anthropic       # Claude
omp auth-broker login kimi-code       # Kimi
omp auth-broker login zai             # 智谱
```

**效果**：自动打开浏览器登录，登录完自动保存，**不需要手动输 Key**

> ✅ **安全**：这个操作只添加服务，不影响现有配置。

---

### 4️⃣ 限制 AI 执行危险命令
**场景**：怕 AI 误删文件、乱跑命令  

**操作**：在终端运行：
```bash
omp config set tools.approvalMode always-ask
```

**可选值**：
| 值 | 效果 | 推荐度 |
|----|------|--------|
| `yolo` | 全自动，不询问 | ⛔ 危险！不建议 |
| `write` | 写文件前确认 | ✅ 推荐 |
| `always-ask` | 每次都确认 | ✅✅ 最安全 |

> 💡 **比喻**：就像手机装 APP 时的权限申请，"总是询问"最安全。

## 🚫 绝对不能碰的配置

| 配置项 | 为什么不能改 | 改了会怎样 |
|--------|-------------|-----------|
| `modelRoles` | 模型分配策略 | AI 变慢、报错、无法使用 |
| `retry.*` | 出错重试机制 | API 失败后无法自动恢复 |
| `compaction.*` | 上下文压缩 | 对话历史丢失、上下文溢出 |
| `auth.broker.*` | 认证代理 | 所有 OAuth 登录失效 |
| `bashInterceptor.*` | 命令拦截规则 | AI 可能用错工具，效率降低 |
| `task.*` | 子代理配置 | 并行任务失败 |
| `extensions` / `disabledProviders` | 扩展管理 | 功能缺失或服务不可用 |

> 🛑 **一句话**：上面这些配置，**除非我明确告诉你改，否则永远不要碰**。

## 🔍 出问题了怎么办？

### 症状 1：OMP 变很慢或一直转圈
- **可能原因**：模型切到了大模型，或思考级别太高
- **解决**：按 `Ctrl+P` 切回主模型，按 `Shift+Tab` 把思考级别调低

### 症状 2：AI 不执行命令或一直问"是否允许"
- **可能原因**：审批模式设成了 `always-ask`
- **解决**：运行 `omp config set tools.approvalMode write`

### 症状 3：AI 回复乱码或报错
- **可能原因**：改了不该改的配置
- **解决**：**立刻截图报错信息发给我**，不要自己尝试恢复

### 症状 4：想恢复默认配置
- **操作**：运行 `omp config reset`
- **效果**：所有配置恢复出厂设置（️ **会清空自定义设置，慎用**）

## 📎 附录：常用终端命令速查

| 命令 | 作用 |
|------|------|
| `omp` | 启动 OMP |
| `omp config list` | 查看所有配置 |
| `omp config get <key>` | 查看单个配置的值 |
| `omp config set <key> <value>` | 修改配置 |
| `omp auth-broker list` | 查看已登录的 AI 服务 |
| `omp auth-broker login <name>` | 登录新的 AI 服务 |
| `omp auth-broker logout <name>` | 退出某个 AI 服务 |
| `omp --version` | 查看 OMP 版本 |
